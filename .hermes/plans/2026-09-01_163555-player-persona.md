# 「我的人设」功能 Implementation Plan

> **For Hermes:** Implement task-by-task on branch `feature/player-persona`; verify then PR.

**Goal:** 给玩家「你」增加一个人设卡（像 NPC 的 `soul.md`：身份/目标/过去/习惯/反应/说话风格），前端可编辑保存，并全面写入旁白（narrator）与角色（NPC）的 prompt，让剧情和角色都理解"我是谁、怎么相处"。

**Architecture:** 玩家不是普通角色（`_RESERVED_NAMES` 含 `player`），人设作为顶层 sidecar 文件 `.player_persona.md` 存于 `CHARACTERS_DIR`，与 `.player_name` 并列。新增 `repository/player_persona.py` 负责读写/解析；`app/prompt_builder.build_player_block` 增强为输出含 persona 的 `<player>` 块，并对 narrator 与非-narrator 都注入；`server.py` 暴露 GET/POST；存档用 `marker` 列表带回 `.player_persona.md`。

**Tech Stack:** Python 3.11+ / FastAPI / 现有 repository-app 分层；Alpine.js 前端。

```python
"""玩家「我」的人设卡（顶层 sidecar，与 .player_name 并列）。"""
from functools import cache
from pathlib import Path
from repository.config import CHARACTERS_DIR

PLAYER_PERSONA_FILENAME = ".player_persona.md"
DEFAULT_PLAYER_PERSONA = """<identity>\n\n</identity>

<goal>
\n</goal>

<past>
\n</past>

<habits>
\n</habits>

<reactions>
\n</reactions>

<voice>
\n</voice>
"""

_SECTION_TAGS = ["identity", "goal", "past", "habits", "reactions", "voice"]


def persona_path() -> Path:
    return CHARACTERS_DIR / PLAYER_PERSONA_FILENAME


def read_player_persona() -> str:
    """读取玩家 persona；不存在返回默认模板。"""
    p = persona_path()
    if not p.exists():
        return DEFAULT_PLAYER_PERSONA
    return p.read_text(encoding="utf-8").strip()


def write_player_persona(text: str) -> None:
    """写入玩家 persona；空文本不写。"""
    if not (t := text.strip()):
        return
    CHARACTERS_DIR.mkdir(parents=True, exist_ok=True)
    persona_path().write_text(t, encoding="utf-8")


def clear() -> None:
    """删除玩家 persona（新开局/清空用）。"""
    persona_path().unlink(missing_ok=True)


def parse_sections(text: str) -> dict[str, str]:
    """把六段 markdown 解析成 {tag: content}。未出现的段返回空串。"""
    sections = {tag: "" for tag in _SECTION_TAGS}
    for tag in _SECTION_TAGS:
        import re
        m = re.search(rf"<{tag}>(.*?)</{tag}>", text or "", re.S)
        if m:
            sections[tag] = m.group(1).strip()
    return sections


def build_player_block(display_name: str, persona: str) -> str:
    """构造注入 prompt 的 <player> 块：显示名 + 六段人设。"""
    if not display_name and not (persona or "").strip():
        return ""
    lines = [f"<player>"]
    if display_name:
        lines.append(f"display_name: {display_name}")
    if (persona or "").strip():
        lines.append("persona:")
        lines.append(persona.strip())
    lines.append("</player>")
    return "\n".join(lines)
```

## Risks / Tradeoffs

1. **角色 prompt 变化可能影响缓存命中** —— 玩家块对所有角色注入会改变 user message；接受（信息价值 > 缓存）。
2. **persona 全文注入 token 开销** —— 玩家自述通常短；若过长再由玩家精简。
3. **`.player_persona.md` 进存档** —— 随 `.player_name` 同机制走 marker，逻辑一致。
4. **不推 main**：全部在 `feature/player-persona`，验证后 PR → merge。
