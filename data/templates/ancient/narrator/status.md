# 故事状态

## 故事阶段
第一幕：渡口相遇，江湖初识

## 当前时间
三月初三 午后

## 场景
醉渡客栈大堂，运河边

## 叙事焦点
玩家刚到客栈，云栖在门口盘问，沈微澜在大堂角落独坐喝茶，观察这个新来的人。

## 待触发事件
- [ ] 【夜雨同行】连夜大雨，玩家与云栖或沈微澜在檐下避雨，无处可去，话反而多了起来
- [ ] 【身份疑云】有人在市集认出"沈远"是女子，沈微澜险些暴露，玩家的反应决定她信任程度
- [ ] 【黑水盟探子】两名黑水盟探子出现在客栈，云栖识出，悄悄示意玩家配合，沈微澜也注意到异常
- [ ] 【线索交汇】玩家无意中提到的一件事，让云栖和沈微澜同时意识到彼此追查的是同一件事
- [ ] 【武馆比试】市集武馆公开比武，掌柜撺掇云栖出场，玩家和沈微澜在台下看，三人视角不同
- [ ] 【深夜账册】沈微澜深夜在灯下查账册，玩家恰好未眠，两人在走廊相遇，说了白天不会说的话
- [ ] 【云栖的噩梦】云栖在梦里喊出师父的名字，玩家听见，云栖否认，但第二天话比平时少
- [ ] 【渡船困局】乘船前往下一线索地，途中遇上暴风，三人被迫在仓内共处一夜
- [ ] 【沈家来人】沈家旁支来人"接沈小姐回家"，沈微澜被迫以男装应对，玩家是唯一知情者
- [ ] 【黑水盟动手】黑水盟在城外设伏，云栖独自去，玩家察觉有异追上——沈微澜也跟来了
- [ ] 【真相碎片】从黑水盟线人口中得到关键信息：沈家案和飞羽门灭门出自同一人指使
- [ ] 【云栖的选择】仇家就在三日后的商船上，云栖要独自去，还是带上玩家——她第一次犹豫
- [ ] 【沈微澜的信】沈微澜写好了给父亲的信，托玩家转交，说"以防万一"，语气平静得不正常
- [ ] 【中秋月下】中秋夜，三人在客栈天台，各自说出了一句平时不会说的话，关系定格
- [ ] 【各奔前程】真相大白后，云栖要继续追，沈微澜要回京，玩家站在渡口，做出选择
